# 초5 연산 트레이너 (MathCure) - 카페24 웹호스팅용 배포 가이드

이 폴더(`cafe24/`)는 **카페24의 일반 웹호스팅(Apache/Nginx + PHP + MySQL)** 환경에 맞추어 제작된 독립형 프로그램입니다.
터미널(SSH) 접속이나 복잡한 SQL 명령어를 전혀 몰라도 웹 브라우저에서 버튼 클릭 한 번으로 자동 설치됩니다.

---

## 🚀 1. 카페24에 업로드하기

1. **FTP 프로그램(알FTP, 파일질라 등)** 또는 **카페24 웹FTP**에 접속합니다.
2. 카페24 계정의 웹 루트 폴더인 `www/` (또는 `public_html/`) 아래로 이동합니다.
3. 이 `cafe24` 폴더 안의 모든 파일과 폴더를 업로드합니다:
   * **방법 A (하위 폴더로 사용 시 - 추천):**
     * `www/mathcure/` 폴더를 새로 만들고 그 안에 이 폴더의 내용물을 모두 올립니다.
     * 접속 주소: `http://내아이디.cafe24.com/mathcure/`
   * **방법 B (메인 홈페이지로 사용 시):**
     * `www/` 폴더 바로 밑에 업로드합니다.
     * 접속 주소: `http://내아이디.cafe24.com/`

---

## 🛠️ 2. 브라우저에서 1초 자동 설치

1. 업로드 후 웹 브라우저(크롬 등)를 켜고 접속 주소로 들어갑니다.
   * 예: `http://내아이디.cafe24.com/mathcure/install.php`
2. **설치 마법사 화면**이 나타나면 아래 정보를 입력합니다:
   * **DB 호스트:** `localhost` (기본값 그대로 둠)
   * **DB 아이디:** 카페24 계정 아이디
   * **DB 이름:** 카페24 계정 아이디 (보통 동일)
   * **DB 비밀번호:** 카페24 MySQL 비밀번호
   * **테이블 접두사 (Prefix):** `mc_` (기본값 그대로 둠)
3. **[DB 연결 및 자동 테이블 생성]** 버튼을 클릭합니다.
4. **끝!** 자동으로 다음 5개 테이블이 접두사(`mc_`)를 달고 생성되며, 대시보드로 바로 이동합니다:
   * `mc_students` (학생 목록)
   * `mc_diagnoses` (진단 기록)
   * `mc_diagnosis_answers` (문제별 채점 답안)
   * `mc_practice_sessions` (온라인 연습 기록)
   * `mc_worksheets` (맞춤 문제지)

---

## 🔒 3. 기존 카페24 데이터와 충돌하지 않는 이유
- 카페24는 1개의 MySQL 데이터베이스를 공유하여 사용합니다.
- 본 프로그램은 모든 테이블 앞에 `mc_` 접두사를 붙이므로, 기존에 카페24에서 운영 중이던 그누보드(`g5_`), 워드프레스(`wp_`), 제로보드 등 기존 데이터와 전혀 충돌하지 않고 안전하게 독립 보관됩니다.

---

## 📁 주요 기능 및 페이지 안내
- **대시보드 (`index.php`):** 학생별 종합 레벨, 최근 정확도, 풀이 속도, 6대 영역 자동화 게이지, 추천 훈련
- **5분 연산 진단 (`diagnosis.php`):** 20문제 타이머, ms 단위 소요시간 측정, 자동 채점
- **진단 결과표 (`diagnosis_result.php`):** 오답 분석, 5일 처방 플랜, 맞춤 훈련지 바로가기
- **맞춤 문제지 (`worksheet.php`):** 60% 취약 / 20% 기초 / 20% 복습 비율 A4 분리 인쇄 레이아웃
- **온라인 풀이 (`practice.php`):** 브라우저에서 실시간으로 풀고 즉시 피드백 받는 인터랙티브 모드
- **학습 기록 (`history.php`):** 누적된 진단 및 연습 성적 이력
- **학생 설정 (`settings.php`):** 학생 추가, 이름/학년 수정, 학생별 격리 초기화
