# 초5 연산 트레이너 (MathCure) - 카페24 웹호스팅용 배포 가이드

이 패키지는 **카페24의 일반 웹호스팅(Apache/Nginx + PHP + MySQL)** 환경에 최적화된 독립형 웹 프로그램입니다.
**회원가입 ➔ 최고 관리자 승인 ➔ 승인된 선생님/회원의 독립 학생 관리** 체계로 구성되어 있어, 학원/공부방/유료 서비스 운영에 바로 투입할 수 있습니다.

---

## 🌟 주요 시스템 구조

1. **회원가입 신청 (`register.php`):**
   * **필수 항목:** 아이디, 비밀번호, 이름(선생님/학부모 실명), 연락처
   * **선택 항목 (비필수):** 소속 (예: OO수학학원, OO초등학교)
   * 가입 신청 즉시 **[승인 대기]** 상태가 되며, 관리자 승인 전에는 접속이 제한됩니다.

2. **최고 관리자 콘솔 (`admin.php`):**
   * **가입 승인 / 반려 / 차단:** 신규 가입자 검토 후 원클릭 승인
   * **비밀번호 초기화:** 회원이 비밀번호를 분실했을 때 관리자가 즉시 임시 비밀번호를 재발급
   * **회원 삭제:** 탈퇴 처리 및 관련 데이터 정리
   * **관리자 계정:** `install.php` 설치 시 원하는 아이디와 비밀번호를 직접 지정하여 안전하게 생성

3. **선생님별 완벽한 학생 데이터 격리 (Multi-tenancy):**
   * A선생님이 등록한 학생들과 B선생님이 등록한 학생들은 서로 완벽히 분리되어 절대 겹치거나 보이지 않습니다.

4. **1초 자동 DB 설치 마법사 (`install.php`):**
   * 복잡한 SQL 명령어 없이 웹 화면에서 DB 아이디/비번만 넣으면 6개 테이블 자동 생성
   * 카페24 1개 DB를 공유하므로 접두사(`mc_`)가 붙어 기존 게시판(그누보드 등) 데이터와 충돌하지 않음

---

## 🚀 1. 카페24에 업로드하기

1. **FTP 프로그램(파일질라, 알FTP 등)** 또는 **카페24 웹FTP**에 접속합니다.
2. 카페24 웹 루트인 `www/` (또는 `public_html/`) 아래로 이동합니다.
3. 이 `cafe24` 폴더 안의 모든 파일과 폴더를 업로드합니다:
   * **추천 (하위 폴더로 서비스 시):**
     * `www/mathcure/` 폴더를 새로 만들고 그 안에 이 폴더의 내용물을 올립니다.
     * 접속 주소: `http://내아이디.cafe24.com/mathcure/`
   * **메인 홈페이지로 사용 시:**
     * `www/` 폴더 바로 밑에 업로드합니다.
     * 접속 주소: `http://내아이디.cafe24.com/`

---

## 🛠️ 2. 브라우저에서 자동 설치 (최초 1회)

1. 브라우저에서 `http://내아이디.cafe24.com/mathcure/install.php` 에 접속합니다.
2. 설정을 입력합니다:
   * **[DB 설정]:** 호스트(`localhost`), DB 아이디, DB 이름, DB 비밀번호, 접두사(`mc_`)
   * **[최고 관리자 계정]:** 사용할 관리자 아이디, 관리자 비밀번호, 관리자 이름/연락처
3. **[DB 연결 & 관리자 계정 생성 완료]** 버튼을 클릭하면 아래 6개 테이블이 자동 생성되고 관리자 계정이 바로 생성됩니다:
   * `mc_users` (회원/관리자 계정)
   * `mc_students` (선생님별 담당 학생)
   * `mc_diagnoses` (5분 연산 진단 기록)
   * `mc_diagnosis_answers` (문제별 채점 답안 & 풀이시간)
   * `mc_practice_sessions` (온라인 연습 기록)
   * `mc_worksheets` (맞춤 문제지)

---

## 🔐 3. 관리자 로그인 및 회원 승인 흐름

1. **관리자 로그인:**
   * 주소: `login.php`
   * 아이디: **`admin`**
   * 비밀번호: **`admin1234!`**
2. **신규 회원 가입 승인:**
   * 상단 네비게이션의 **[🛡️ 회원 관리]** 클릭 (승인 대기 인원 뱃지 표시)
   * 신청자 정보(이름, 연락처, 소속) 확인 후 **[승인]** 버튼 클릭
3. **승인된 회원(선생님):**
   * 로그인 후 [학생 관리]에서 자기 학생들을 추가하고, 5분 진단 테스트 및 맞춤 훈련지를 마음껏 이용할 수 있습니다.
